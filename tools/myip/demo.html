My IP — WebRTC exposure demo

Collects the addresses WebRTC discloses through ICE candidates, classifies each (private / link-local / CGNAT / loopback / ULA vs public), renders the leak verdict against the public IP you paste in (copy it from any "what is my IP" page), and reads the NAT's mapping behaviour off the same candidates. With STUN enabled the probe's only network traffic is STUN binding requests to two public servers (Google and Cloudflare); untick it for a fully local probe with no NAT reading. Needs a browser with WebRTC.
