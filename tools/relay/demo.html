Relay upload — demo

Exercises the Relay tool's batch queue, concurrency pool, preflight, progress and lifetime model. The uploader below is an injected fake — the module takes the transport as a function parameter, and this page passes one that just ticks progress on a timer and mints an example.invalid URL. Nothing leaves this page. (The real site injects an XHR transport for its upload endpoint; see the README.)

Text document routing (pure, nothing uploaded)

On the site a single dropped .md/.txt opens in the editor instead of uploading; this reports what textDropRoute() would decide for the chosen files and whether the bytes decode as round-trip-safe text. The 1 MiB editor cap applies.

History pruning (pure)

Same rule as the site's reload path: expired entries are pruned, storage is rewritten only when something was pruned, and an emptied history removes the key instead of writing '[]'.

Video → keyframes ZIP (fully local)

Analyzes the clip, extracts the most-changed keyframes, builds a contact sheet and packs a store-only ZIP — entirely in this page; the video is never sent anywhere. Cap set to 15 MB here.
